# Privacy policy — AI Hype Tycoon

Effective 25 August 2026.

AI Hype Tycoon is a single-player satire. It does not require an account.

**What we store.** Game progress is saved on the device (browser local storage, or Android SharedPreferences). There is no server-side player database.

**What we do not collect.** No name, email, location, contacts, advertising ID, or analytics SDK in the game. No third-party ads.

**Network.** The Android build is fully offline. The web build only needs a network to load the page itself.

**Children.** The game is a satirical business sim rated for teens and up. It does not target children and does not collect data from them.

**Contact.** Open an issue on the GitHub repository for this project.
